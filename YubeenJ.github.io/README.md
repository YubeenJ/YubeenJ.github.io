# Yubeen Jeong — academic website

A personal academic website for GitHub Pages, with a persistent ocean-blue profile sidebar, responsive layouts, and one Calibri-style font family throughout.

**처음 업로드:** [START_HERE.md](START_HERE.md)  
**직접 수정:** [EDITING.md](EDITING.md)

## Everyday editing

- Homepage: `index.md`
- Research: `research.md`
- Publications: one Markdown file per paper in `_publications/`
- Manuscripts: `_manuscripts/`
- Experience: `experience.md`
- CV: `cv.md` and `assets/files/CV_YJeong.pdf`
- Contact and shared profile: `contact.md` and `_data/profile.yml`
- News: `_data/news.yml`

GitHub Pages builds these Markdown files with Jekyll. Set **Settings → Pages → Deploy from a branch → main / (root)**. No custom Actions workflow, paid theme, Python script, or external font service is required.

The site is configured for `https://yubeenj.github.io/`. Its design is inspired by the requested sidebar-based academic reference; it is not a copy of a paid theme.

Content and photographs are based on the CV and existing repository supplied by the owner. For font licensing and asset provenance, see [LICENSES.md](LICENSES.md).
